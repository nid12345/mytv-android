## 关于本仓库

本仓库是 [yaoxieyoulei/mytv-android](https://github.com/yaoxieyoulei/mytv-android) 的**个人定制分支**，
完整保留原项目的界面设计、排版与全部功能，仅在此基础上做少量自用调整：

- 默认直播源改为自用源
- 节目单默认源改为国内可直连的实时源，并修复了频道名写法差异（如 `CCTV-1` 与 `CCTV1`）导致的节目单匹配失败
- 修复台标不显示的问题，并做成多级自动回退：**内置 54 个常用频道台标**（离线可用、瞬时显示）
  → **自建台标镜像仓库**（CDN 加速 + 直连）→ 上游原站 → 上游国内镜像；
  同时按台标仓库的命名规范换算文件名（央视由 `CCTV-1` 换算为 `CCTV1`）
- 新增 DLNA 投屏：播放界面快捷操作栏第一项「投屏」，可把当前频道推送到局域网内的电视、电视盒子播放
- 内置 斗鱼直播 / 虎牙直播 / YY轮播 三个订阅源，可在「换源」里一键切换
- 收藏支持跨订阅源保留：收藏时保存频道快照（名称 / 节目单名 / 线路 / 台标），
  切换到其它订阅源后「我的收藏」里依然能看到并播放，除非自己取消收藏
- 三段式选台界面（左分组 / 中频道 / 右节目信息）与 16:9 显示模式为默认设置
- 添加自定义直播源支持手动输入名称与链接，不必再依赖手机扫码推送

台标镜像仓库：[nid12345/mytv-logos](https://github.com/nid12345/mytv-logos)，
内容同步自 [fanmingming/live](https://github.com/fanmingming/live) 的 `tv/` 目录。

**特别感谢原作者 [@yaoxieyoulei](https://github.com/yaoxieyoulei)**，以及

本项目界面与全部基础能力均来自他们。

## 定制版更新日志

### 1.7

- **修复「换源/选台菜单快速下滑卡退」**：根因是焦点恢复逻辑里按下标取 `FocusRequester`
  没有兜住越界。经典选台的**分组栏、频道栏**（以及节目单的日期栏）都在用
  `itemFocusRequesterList[list.indexOf(记住的那一项)]` 恢复焦点，而 `indexOf` 会返回 **-1**：
  - 打开应用 15 秒后，**线路测速完成会整份替换频道列表**（每个频道的 `urlList` 被重排、
    对象全是新的），此时「记住的那一项」在新列表里已经找不到了；
  - 分组被全部隐藏、订阅源解析为空、或列表里没有当前频道时，同样找不到。

  快速下滑会高频触发「焦点恢复 + 重组」，正好撞上这个窗口，于是崩退。
  修复方式：焦点恢复整体兜异常、按下标取值的入口统一换成 `getOrNullAt`，
  列表重建后按**名字**重新绑定记住的那一项；同时把分组栏的 `FocusRequester` 列表
  按「分组名序列」缓存（原来每次重组都重建，滚动时实例被反复替换）。
  > 该项目原本在节目单列表上就留着一处 `// FIXME 闪退`（同一写法被注释掉），本轮一并修好并重新启用。

- **新增「自动连播」**：潮汕节目回放这类**点播源**，一个视频播完自动接着播下一个
  （同分组内顺着播，本分组播完接下一个分组；整源播完停住并提示）。
  直播源不受影响。开关在「设置 → 直播源 → 自动连播」，默认开启。

- **打通定制版升级通道**：更新检查与下载全部改到**本仓库自己的 Release**
  （tag `custom-vX.Y`，附件即定制版 APK）。
  - 原实现指向的是**上游官方更新接口**，那条通道发的包是官方签名、且包名不同，
    点升级会装出一个「另一个应用」；而且下载地址前缀用的 `ghp.ci` 已经停止服务，
    链接本身就是死链；
  - 新解析器能正确吃下 `custom-v1.7` 这类 tag（旧解析器 `substring(1)` 会得到
    `ustom-v1.7`，版本比较直接抛异常）；
  - **国内直连 GitHub 不稳**，检查与下载都带镜像回退（实测 `gh-proxy.com`、
    `ghproxy.net` 对 Release 附件可用），可在「设置 → 更新 → 下载线路」里选
    自动 / 直连 / 镜像优先；
  - 下载完先校验是不是真 APK（ZIP 头 + 体积）再调起安装，避免镜像返回 HTML 错误页
    被当成安装包；
  - 「设置 → 更新」保留**升级提醒**开关（关掉就不自动检查）、**更新强提醒**开关
    （全屏提醒 / 仅消息提示）、更新通道、下载线路，并新增「检查更新」手动入口。

- **新增崩溃记录**：未捕获异常会写进应用私有目录，下次启动注入到「设置 → 日志」。
  电视/盒子上没法连电脑看 logcat，有了这个即使再出问题也能直接把堆栈读出来。

### 1.6

- **线路测速改为两阶段，解决「默认源打开就卡」**：原来只比「响应头耗时」，
  于是那些**响应很快、但拉不动大分段**的转发线路会被排到第一位（默认源里 HLS 多为
  10 秒一个分段、直播窗口只有 3 段，一条拉不动就是十几秒的卡顿）。现在：
  1. 廉价探测覆盖全部线路，HLS 线路改为「读完整个清单再计时」——第三方转发站的清单
     经常要 2~3 秒才回，而直播 HLS 每隔一个分段时长就要重刷一次清单；
  2. 每个频道挑响应最快的前 2 条，**真拉一小段媒体数据实测下行速率**（250ms / 192KB 封顶）；
  3. 排序改为「实测速率高的 → 响应快的 → 未知 → 打不开」。

  实测没取到数据的线路不做惩罚（可能只认特定 UA），仍按响应速度参与排序。
  一个频道的线路越少、越不需要测，测速开关与设置项都不变

### 1.5

- **修复推送 APK 后「调起安装失败」**：安装 Intent 改为多套写法依次尝试
  （`ACTION_VIEW` + apk MIME → `ACTION_INSTALL_PACKAGE` + `EXTRA_NOT_UNKNOWN_SOURCE`），
  兼容只认后者的定制 ROM/电视盒；清单里补上系统安装器的包可见性声明；
  失败时把真实原因显示出来（不再是笼统的「调起安装失败」）。
  「安装包管理」在系统未放行「安装未知应用」时，顶部会给出一键跳设置的入口
- **订阅源改完立即生效，不用重启应用**：手机扫码网页/推送接口写入订阅源后，
  会通知正在运行的界面立刻切到该源并重载频道列表；切换订阅源时先清缓存再加载，
  避免把上一个源的缓存内容当成新源的显示出来
- **显示比例改为「全局默认 + 单频道记忆」**：默认全部 16:9；
  某个频道单独设过比例（如 YY轮播的老三国用 4:3）后，下次打开这个频道优先用它自己的设置，
  其它频道不受影响；比例面板新增「3:4」，「设为全局默认」会清掉本频道的单独设置。
  （原 1.4 的「按订阅源整体记忆」已取消——它会让同一订阅源里所有频道一起变）
- **潮汕节目回放默认关闭**，订阅地址同时内置成一个可切换的独立订阅源
  （「换源」/「自定义直播源」里可见）；不显示台标位，标题可用宽度也从 220dp 提到 300dp，
  长标题（如「今日视线 20260920」）不再被挤掉

### 1.4

- **修复推送 APK 后不弹安装界面**：Android 7 以下系统安装器读不到应用私有目录里的文件，
  现在把安装包转到外部缓存并放开权限再调起安装；调起失败会提示到「安装包管理」手动安装。
  安装包同时会持久保存，不用为装第二遍再传一次
- **新增「安装包管理」**（设置 → 推送 → 安装包管理）：列出收到的安装包
  （确认键安装、长按删除），并列出已装应用（确认键调起系统卸载）
- **显示比例按订阅源记忆**：在订阅源 A 里选了 4:3，之后打开订阅源 A（或其中频道）自动套用 4:3，
  切到其它订阅源互不影响；默认直播源不参与记忆，恒定 16:9。频道名级别可单独覆盖
- **记住上次频道**：默认打开应用就接着播上次退出时的频道；
  设置 → 直播源 → 「记住上次频道」可关闭（关闭后从第一个频道开始）
- **分组显隐按源记忆 + 全部分组管理**：每个订阅源记住自己的分组隐藏设定，
  切换订阅源、重启应用后保持；设置 → 直播源 → 「全部分组管理」可在一个界面里
  统一设定所有订阅源的分组显隐
- **「系统应用」入口**：选台界面分组栏最底部新增带图标的「系统应用」，
  列出本机可启动的应用，点击跳转，跳转前自动暂停正在播的直播
- **内置「潮汕节目回放」**：浏览默认直播源时，其栏目（今日视线、汕头新闻等）
  压平为「潮汕节目回放」分组显示在「更新时间」之后；加载失败自动跳过不影响默认源。
  设置 → 直播源 → 「潮汕节目回放」可整体隐藏（点播回放地址不参与线路测速）

### 1.3

- **修复打开应用后反而播放不了**：线路测速与播放抢带宽所致。现在测速只在应用打开
  15 秒后开始（先让首帧播起来），并发从 24 降到 4、单条超时 1.5 秒、每批之间停顿 200ms、
  正在播放的频道不参与探测；结果缓存 12 小时。设置 → 直播源 → 「线路测速排序」可整体关闭
- **内置斗鱼直播 / 虎牙直播 / YY轮播**：三个订阅源已内置到「换源」列表，一键切换；
  它们不参与线路测速（每频道单线路，测速只会白占带宽）
- **跨源收藏**：收藏保存频道快照（名称 / 节目单名 / 线路 / 台标），在斗鱼收藏的频道，
  切回默认源或其它订阅后依然在「我的收藏」里、依然能播；只有自己取消收藏才会移除
- **默认设置**：三段式选台界面、16:9 显示模式改为默认（新装与升级均生效，改过的设置不受影响）
- **手动添加订阅源**：「添加自定义直播源」弹层左侧新增名称 + 链接输入框，可直接填写保存；
  右侧保留手机扫码入口

### 1.2

- **修复节目表加载不出来**：定位到两个原因并都已处理
  1. 默认节目单用的是 `e.xml.gz`——同目录下的预生成文件，拿到手时内容常常已停在生成那一刻，
     凌晨就会出现「当前时刻查不到节目」。现已改用实时生成的 `e.xml`，并在读取配置时自动迁移旧地址；
  2. 原逻辑在「刷新时间阈值（默认 2 点）之前」会直接返回**空**节目单，于是凌晨整份节目单凭空消失。
     现在阈值只决定「要不要主动刷新」，不再让节目单变空。
  另外做了多源补齐：主源缺的频道会自动从其余节目单来源补上（并集覆盖更全），
  单个来源超时或格式异常时只跳过该来源，不会连累整份节目单。
- **多线路按播放效果排序**：同一频道的多条线路会做一次轻量连通性探测（只发很小的 Range 请求、
  只等响应头，不真正拉流），按连接耗时从快到慢重排，最快的排第一条；
  打不开的线路排到最后。结果缓存 6 小时，启动时先用源里原始顺序显示、测速完成后自动刷新列表，
  当前正在播放的线路不会被打断。
- **新增「换源」快速切换入口**：选台界面左侧分组栏最上方新增「换源」，右侧直接列出全部订阅链接
  （内置源 + 历史订阅源），选中即切换；列表末尾是「＋ 添加订阅链接」，可随时新增订阅。
- **设置项**：设置 → 直播源 → 「直播源快速切换」，可显示/隐藏上面的「换源」入口。

## 使用

### 操作方式

> 遥控器操作方式与主流视频播放软件类似；

- 频道切换：使用上下方向键，或者数字键切换频道；屏幕上下滑动；
- 频道选择：OK键；单击屏幕；
- 设置页面：按下菜单、帮助键，长按OK键；双击、长按屏幕；

### 触摸键位对应

- 方向键：屏幕上下左右滑动
- OK键：点击屏幕
- 长按OK键：长按屏幕
- 菜单、帮助键：双击屏幕

### 自定义设置

- 访问以下网址：`http://<设备IP>:10481`
- 打开应用设置界面，移到最后一项
- 支持自定义订阅源、自定义节目单、缓存时间等等

### 自定义订阅源

- 设置入口：自定义设置网址
- 格式支持：m3u格式、tvbox格式

### 多订阅源

- 设置入口：打开应用设置界面，选中`自定义订阅源`项，点击后将弹出历史订阅源列表
- 历史订阅源列表：短按可切换当前订阅源（需重启），长按将清除历史记录；该功能类似于`多仓`，主要用于简化订阅源切换流程
- 须知：
    1. 当订阅源数据获取成功时，会将该订阅源保存到历史订阅源列表中
    2. 当订阅源数据获取失败时，会将该订阅源移出历史订阅源列表

### 多线路

- 功能描述：同一频道拥有多个播放地址，相关标识位于频道名称后面
- 线路排序：启动后会后台给各线路做一次轻量测速，按连接速度从快到慢重排，最快的排第一条；
  打不开的线路排到最后（结果缓存 6 小时）
- 切换线路：左右方向键；屏幕左右滑动
- 自动切换：当当前线路播放失败后，将自动播放下一个线路，直至最后
- 须知：
    1. 当某一线路播放成功后，会将该线路的`域名`保存到`可播放域名列表`中
    2. 当某一线路播放失败后，会将该线路的`域名`移出`可播放域名列表`
    3. 当播放某一频道时，将优先选择匹配`可播放域名列表`的线路

### 直播源快速切换（换源）

- 功能入口：打开应用选台界面，左侧分组栏最上方「换源」；可在 `设置 → 直播源 → 直播源快速切换` 中隐藏
- 使用方法：右侧列出全部订阅链接（内置源 + 历史订阅源），选中即切换；列表末尾「＋ 添加订阅链接」可新增订阅

### 自定义节目单

- 设置入口：自定义设置网址
- 格式支持：.xml、.xml.gz格式

### 多节目单

- 设置入口：打开应用设置界面，选中`自定义节目单`项，点击后将弹出历史节目单列表
- 具体功能请参照`多订阅源`

### 当天节目单

- 功能入口：打开应用选台界面，选中某一频道，按下菜单、帮助键、双击屏幕，将打开当天节目单
- 须知：由于该应用不支持回放功能，所以更早的节目单没必要展示

### 频道收藏

- 功能入口：打开应用选台界面，选中某一频道，长按OK键、长按屏幕，将收藏/取消收藏该频道
- 切换显示收藏列表：首先移动到频道列表顶部，然后再次按下方向键上，将切换显示收藏列表；手机长按频道信息切换
